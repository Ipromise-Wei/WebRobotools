# v0.7.5 版本说明

发布日期：2026-09-28

本版修正 v0.7.4 中“停止建图”过度扩大为整栈停止的问题，把建图会话和机器人基础 I/O 明确分层。

## 停止边界

点击“停止建图”后，系统按依赖逆序停止：

1. Frontier 自动探索；
2. Nav2 导航；
3. 工控机地图/导航通信中继；
4. SLAM Toolbox。

以下基础进程继续运行：

- Ranger Mini V3 底盘；
- Livox MID-360；
- FAST-LIO；
- 点云转激光。

只有“全部停止”或关闭基础功能模块才会回收全部 Web 受管进程。

## 模式切换

手动建图与自动建图切换时，同样只重启上述建图会话层。这会清除当前未保存的实时地图，并使新 SLAM Toolbox 进程从空白地图开始，但不重启底盘、雷达、FAST-LIO 或点云转激光。

已保存在 `/home/hzauaiot/.local/share/webrobot/maps` 的 YAML/PGM 地图文件仍然保留。

## 并发保护

工控机运行代理新增受限的 `stop-tasks` 动作。执行批量停止前会先取消正在进行的启动编排，然后按配置的逆序回收指定进程组，避免启动线程在停止后又把建图模块拉起。浏览器不能传入任意命令；可停止的任务 ID 由后端固定。

## 验证

- 后端测试 20 项通过，1 项 ROS2 环境测试跳过。
- 新增运行代理测试，确认批量停止 SLAM 后底盘任务仍然保持运行。
- 前端 TypeScript 类型检查与生产构建通过。
