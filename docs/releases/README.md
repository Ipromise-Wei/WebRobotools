# 版本改进日志

本目录保存正式发布版本的完整改进说明；`CHANGELOG.md` 是全部版本的简要变更索引。

## 发布要求

每次创建 `vX.Y.Z` Git 标签时，**必须在同一提交中**完成以下内容：

1. 在根目录 `CHANGELOG.md` 新增该版本、发布日期和面向使用者的改进摘要。
2. 新建 `docs/releases/vX.Y.Z.md`，说明新增或修复内容、配置或部署影响、验证结果，以及安全边界或已知限制。
3. 同步更新后端与前端版本号，并在 README 的版本入口中链接最新版本说明。

未包含上述日志的提交不得创建正式版本标签或 Release。
