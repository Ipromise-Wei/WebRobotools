# v0.6.0 版本说明

发布日期：2026-09-28

本版为移动机器人工作站新增受管建图流程。Web 端只触发服务端预定义的运行方案；底盘、SLAM、Nav2 与 Frontier 始终由工控机执行，浏览器不能提交任意 Shell 或 ROS 命令。

## 建图模式

- **手动建图**：按依赖顺序启动 Ranger Mini V3、Livox MID-360、FAST-LIO、点云转激光、SLAM Toolbox 与受速度看门狗约束的 Nav2。操作者通过原有手动驾驶控制完成建图。
- **自动建图**：在手动建图所需模块就绪后，启动 `frontier_exploration_ros2`。探索器以冷启动模式运行，随后由 `frontier_exploration_ctl start` 显式开始探索；停止时会先请求 `frontier_exploration_ctl stop`，避免 Frontier 与 Nav2 留下活动目标。

切换回手动建图时，系统会先停止 Frontier，防止自动探索与人工驾驶同时接管导航。

## 地图文件库

- **保存当前地图**：调用工控机上的 `nav2_map_server map_saver_cli` 保存当前 `/map`，生成标准 ROS 地图 YAML 与 PGM 文件。
- **导入地图**：在 Web 端选择同一张地图的 YAML 与 PGM 文件；服务端校验名称、YAML 基本字段和 PGM 文件头后上传到工控机。
- **存储位置**：`/home/hzauaiot/.local/share/webrobot/maps`。

导入仅建立地图文件库，不会中断 SLAM，也不会自动切换到静态地图定位。静态地图加载与 AMCL/定位导航是独立的运行模式，需在后续版本中明确提供。

## 使用边界

- 自动建图前必须清空作业区域，确认现场物理急停有效，并由现场人员监控机器人。
- Web 停止、Frontier 停止和速度看门狗均不替代硬件急停。
- 工控机需要具备 `frontier_exploration_ros2`、`nav2_map_server` 与已构建的 `/home/hzauaiot/songwei/frontier_ws` 工作区。
