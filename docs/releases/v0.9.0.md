# v0.9.0 版本说明

发布日期：2026-09-29

本版补齐机械臂 3D 示教预览、按需视频和模块启动反馈，并修复工控机负载较高时 SLAM 就绪检测过早失败的问题。

## RML63 3D 示教

机械臂工作站左侧主画面新增“实时视频 / 3D 示教”切换。3D 视图使用 WebGL 展示六轴串联结构和末端坐标轴，并提供：

- 真机姿态：跟随机械臂实时关节反馈；
- 目标预览：右侧 J1～J6 修改后立即预览，但不直接驱动真机；
- 左键旋转、滚轮缩放、右键平移及默认视角复位；
- 六轴角度读数、待确认状态提示，以及放弃预览并重新读取真机。

目标仍只能通过原有“执行关节运动”按钮下发，并继续经过真机连接、运动指令许可、工作坐标系、工具系、运动状态和人工确认检查。3D 模型是依据 RML63 关节结构及主要连杆尺寸构建的轻量模型，不替代碰撞检测、离线轨迹规划或控制器自身限位。

## RealSense 按需启停

机械臂页面恢复显式视频开关。服务启动时不会自动打开相机；只有页面启用视频且浏览器连接 MJPEG 时才创建采集、FFmpeg 编码和 SSH 传输链路。关闭开关会停止采集线程并清理连接状态。若配置使用外部视频 URL，则仍由服务端配置管理，页面不能动态启停。

从视频切换到 3D 示教会卸载当前图像连接，从而释放无人观看时的传输负担；运行时启用状态不写回配置文件，服务重启后仍采用配置默认值。

## 模块启动反馈与 SLAM 就绪检测

基础模块以及手动/自动建图编排现在显示：

- 已完成任务数和百分比；
- 当前正在启动或等待就绪的模块；
- SLAM 或 Frontier 的明确失败原因。

SLAM `/map` 探针不再使用固定 3 秒的 shell `timeout`。运行代理为单次探针设置 15 秒超时，探针超时只代表本轮未就绪，会在 60 秒总期限内继续重试；这样可以容纳繁忙工控机上的 DDS 发现延迟，同时继续保证启动过程有界、可取消。

## 登录入口

登录页注册为独立 `/login` 路由，并在路由进入前完成会话初始化。未认证访问会跳转到登录页并保留安全的站内返回路径；登录成功后返回原页面；会话失效时断开机器人状态连接并回到登录页。未知路径统一回到登录入口。

## 部署影响

- 前端新增 `three` 与对应 TypeScript 类型依赖，部署前需要重新执行 `npm install` 和生产构建。
- 远程运行清单新增可选 `ready_probe_timeout` 字段，默认 15 秒；旧清单中的简单 `timeout N <command>` 包装会由运行代理兼容移除。
- 运行代理脚本或配置有变化时，重启 Web 后端后由现有部署流程同步到工控机。
- 本版没有改变运动指令、导航目标或夹爪控制的服务端白名单边界。

## 已知边界

- 3D 示教当前用于关节姿态监看与目标预览，不计算自碰撞、环境碰撞或可达性，也不支持在模型上直接拖动单个关节。
- WebGL 不可用时实时状态和右侧真机控制仍可使用，但 3D 画布无法显示。
- Web 停止按钮不是安全等级急停；真机操作时仍必须确保示教器或物理急停可触达。

- 覆盖相机运行时启停、SLAM 就绪探针超时重试、建图状态清理与运行编排测试。
