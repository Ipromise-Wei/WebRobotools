# v0.6.4 版本说明

发布日期：2026-09-28

这是针对建图与导航同时运行时持续高 CPU、接口延迟的资源隔离版本。

## 根因处理

Nav2 的 `/plan` 会频繁更新。旧链路把路径与地图共用同一个版本号，因此每次路径变化都会把整张 OccupancyGrid 再次压缩、传输、解压和渲染，即使 `/map` 本身没有变化。大型地图下，这会持续占满一个 Python CPU 核心，造成 `/health`、认证和控制接口超时。

本版把地图版本与路径版本分开：

- `/map` 更新时才发送压缩后的完整地图；
- `/plan` 更新时只发送路径点及 `path_revision`；
- 前端仅重新绘制路径，不重建地图纹理；
- 路径在地图压缩期间更新时复用正在生成的地图负载，不会重复压缩。

## 地图资源上限

- Web 显示地图最多 262144 个格子，默认最多每两秒更新一次。
- 较大地图按整数倍采样并相应增大显示分辨率，地图坐标范围保持不变。
- 后端保存 ROS2 原始分辨率栅格引用，用于地图范围、已知空闲栅格和障碍物检查；浏览器显示的降采样不会参与安全判断。

## 验证与边界

- 已完成 Python 编译检查、前端 TypeScript 检查和生产构建；新增路径/地图版本及降采样回归覆盖。
- 在更新后的服务器上，停留在地图页时应观察到：路径可以连续更新，但 Uvicorn 不再因每个路径更新重传整图而持续占满一个 CPU 核心。
- 本版不改变 ROS2 建图频率、Nav2 行为、看门狗、目标安全校验或物理急停要求。
