# v0.8.0 版本说明

发布日期：2026-09-28

本版将“机器人可驾驶”与“正在建图”拆成两个独立状态。默认运行基线自动就绪，SLAM 和 Frontier 只在用户选择建图时运行。

## 默认启动基线

Web 后端启动后异步初始化工控机；如果 SSH 或工控机暂时不可用，地图轮询保持关闭并每 10 秒重试完整初始化：

1. 停止上一次可能残留的 SLAM、地图/导航中继、Nav2 和 Frontier 会话；
2. 清除 ROS2 适配器及 Web 地图管理器中的地图和路径副本；
3. 启动底盘、Livox MID-360、FAST-LIO、点云转激光、工控机通信中继和 Nav2；
4. 确认会话切换后再次清除可能的末尾地图帧，然后才启动 Web 地图轮询。

启动初始化在后台运行，`/health` 和登录页不必等待工控机所有模块就绪。建图勾选在基础功能与 Nav2 全部进入 `running` 之前保持禁用。

## 地图空白保证

在默认方案初始化完成前，`VisualizationService` 不会把 ROS2 适配器中的数据写入 Web `MapManager`。因此旧中继或旧 SLAM 在回收过程中发出的最后一帧不会被新页面加载。工控机会话完成切换后，后端再次同步清空两级缓存，然后开放实时地图更新。

已保存在 `/home/hzauaiot/.local/share/webrobot/maps` 的 YAML/PGM 文件不参与自动加载，也不会被删除。

## 建图模式

- **不勾选**：SLAM 与 Frontier 关闭。手柄/键盘驾驶经工控机速度看门狗正常转发，但不发布占据栅格地图。
- **手动建图**：只增加 SLAM Toolbox。操作者驾驶底盘时生成地图。
- **自动建图**：按依赖启动 SLAM Toolbox 和 Frontier。如果已在手动建图，则仅增加 Frontier，不重置当前地图。
- **自动切手动**：先请求 Frontier 停止当前探索，再回收 Frontier 进程，SLAM 继续运行。
- **取消当前勾选**：停止 Frontier 和 SLAM，同步清空 Web 地图/路径，但保留底盘、传感器、通信中继和 Nav2。

运行代理版本升级为 4，状态中增加 `orchestrating_profile`。因此即使自动方案尚在等待 SLAM 地图就绪，页面也能正确显示“自动建图启动中”，并允许操作者取消。

## 已知边界

- 默认启动的 Nav2 在无地图时处于等待地图状态，Web 目标导航会被地图安全校验拒绝；这不影响手柄驾驶。
- 启动自动建图前必须确认现场物理急停可用并由人员持续监控。
- 程序启动只清理内存中的实时地图，不删除地图文件库中的已保存文件。
