# v0.5.0 版本说明

发布日期：2026-09-22

本版将底盘、机械臂和视觉操作集中到需要登录的 Web 工作站。底盘和机械臂指令面向真机；页面不会伪造相机、地图或机械臂反馈。

## 这个版本具备的功能

- **登录与访问控制**：管理员登录后才能访问控制 API、API 文档及机器人/地图实时 WebSocket。首次启动生成本机凭据与随机密码；支持重置密码、会话到期和登录失败锁定。浏览器会话使用签名的 HttpOnly Cookie。
- **底盘与 ROS2 模块管理**：可在页面独立启动/停止底盘、Livox 雷达、FAST-LIO、点云转激光、SLAM Toolbox 和 Nav2，查看运行状态与日志，也可按依赖关系一键启动。键盘方向键或 `W/A/S/D`、虚拟摇杆均支持持续驾驶及行进中转弯；松开输入、窗口失焦或速度指令超时会停止持续控制。
- **地图、导航和视频**：同一底盘工作站展示 SLAM 栅格地图、Nav2 路径、机器人位姿与 RealSense 真机视频。地图支持平移、缩放、跟随、图层切换；可点选目标位置、拖动设定最终朝向，向 Nav2 发送目标并取消。地图缓存按钮只清 Web 端内存快照。
- **机械臂和夹爪**：机械臂工作站提供 RML63 六轴状态、关节目标、TCP 直线运动、待命位、停止和工具 IO 夹爪控制，显示关节/TCP 实时数据与末端相机画面。运动前执行工作/工具坐标系、关节限位、工作空间和碰撞等级等安全检查。

## 相较 v0.4.0 的改进

1. **补齐登录保护**：新增独立登录页与服务端会话校验；REST、相机流、API 文档和两个实时 WebSocket 均受会话保护。凭据只存于被 Git 忽略的本机文件，不随版本上传。
2. **地图上直接下发 Nav2 目标**：导航卡显示就绪原因、目标坐标、执行状态和取消操作。后端要求受管底盘/Nav2、近期地图与定位、速度看门狗和 Action Server 就绪，并拒绝地图外或非已知空闲栅格目标。导航期间锁定非零手动驾驶。
3. **统一导航速度安全链路**：Nav2 的平滑速度和恢复动作经工控机速度看门狗转发到底盘；Web 导航心跳或速度断流时输出零速度。工控机 Nav2 启动文件若不符合预期，模块拒绝启动，避免直接绕过看门狗。
4. **不再从 Web 重配 CAN0**：移除需要 sudo 的 CAN0 开关。底盘启动前和运行中只读检查工控机 `can0` 已是 UP、500000 bit/s 且未进入 BUS-OFF；不满足条件时拒绝或停止底盘任务。旧版 CAN0 任务仍在运行时会提示迁移并锁定相关模块操作，不自动拉低网卡。
5. **机械臂连接改为显式操作**：服务启动、页面轮询和异常断线不再自动连接真机。用户点击连接后，Web 后端通过工控机桥接器从 `enp4s0` 连接 RML63；运动中禁用断开，断开前释放夹爪 IO。
6. **工作站布局与提示优化**：压缩文本和控制区域，扩大地图与视频显示占比；地图导航、模块状态、手动驾驶和安全锁定提示分区显示。

## 部署前提与使用边界

- Web 服务器和工控机需位于可通信的局域网，配置免密 SSH 与同一 ROS2 Domain；工控机需具备对应的 ROS2 Humble 功能包，Web 后端需具备 `nav2_msgs`。
- `can0` 由工控机系统或现场人员预先配置，本版 Web 只读取状态，不负责启停。导航需从 Web 模块面板启动受管底盘和 Nav2；不要同时运行另一套直接发布 `/cmd_vel` 的导航脚本。
- 地图缓存清除不删除 SLAM 地图文件，也不重置建图；地图原点带旋转时不允许从 Web 地图选点。RealSense 视频和机械臂控制依赖对应真机、设备节点与网络链路。
- Web 的“停止运动/停止导航”不是安全等级急停。运行真机时仍须保证现场物理急停可用。此版本未在本次提交过程中运行自动化测试或进行真机联调，运动效果与安全链路需现场验证。
