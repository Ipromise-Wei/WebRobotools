# v0.6.2 版本说明

发布日期：2026-09-28

这是针对 Web 服务端、工控机视频通道与浏览器轮询的资源优化版本。

## 地图链路

- 工控机 ROS2 仍按其原始频率发布 `/map`，SLAM 不被限速。
- Web 后端仅每秒创建一次完整 OccupancyGrid 快照；地图尺寸、分辨率或坐标系改变时会立即刷新。
- 已发布的地图快照采用替换而非原地修改，地图管理器、REST 和 WebSocket 不再为每次读取深拷贝大数组。

这解决了建图期间重复复制大型栅格地图导致 Python 长时间占用 CPU、`/health` 和认证接口超时的问题。Web 地图画面的刷新上限为 1 FPS，适合建图监看与选点；它不影响 ROS2 内部建图、Nav2 或速度看门狗频率。

## RealSense 视频

- 后端启动、登录页和不显示相机的页面不再连接工控机或启动 FFmpeg。
- 进入包含视频面板的页面时才建立单个 SSH/FFmpeg 采集通道；离开最后一个视频页面后自动关闭。
- 默认帧率调整为 15 FPS、分辨率保持 1280×720。若现场确有高速视觉需求，可在确认工控机资源充足后将 `visualization.realsense.fps` 调回 30。

## 轮询与验证

- 前端的运行状态轮询从 3 秒调整为 5 秒，并确保前一轮尚未结束时不发起下一轮；其余状态轮询也增加同类并发保护。
- 已完成 Python 编译检查、前端 TypeScript 检查和生产构建。
- 新增地图快照限速、无深拷贝交接以及相机按需启动的回归测试。完整 ROS2 压力验证应在目标服务器更新后，使用 `top -H -p <uvicorn_pid>` 和本机 `/health` 请求观察。

## 安全边界

本版本不改变 ROS2 模块启动顺序、速度看门狗、Nav2 目标安全检查或物理急停要求。停止 Web 服务仍会发布零速度并尝试取消受管导航目标；物理急停始终是现场最高优先级的安全措施。
