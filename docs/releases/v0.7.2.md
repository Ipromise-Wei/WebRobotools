# v0.7.2 版本说明

发布日期：2026-09-28

本版将底盘建图工作流收束为“基础功能模块 + 手动/自动建图”的直接操作方式，并修正若干会影响现场控制与浏览器资源占用的交互问题。

## 基础功能模块

“模块控制”不再分别展示底盘、雷达、FAST-LIO、点云转激光、SLAM Toolbox 和工控机实时通信中继六个开关。这六项现在合并为“基础功能模块”，一次启动会按已有依赖顺序启动它们：

1. Ranger Mini V3 底盘；
2. Livox MID-360；
3. FAST-LIO；
4. 点云转激光；
5. SLAM Toolbox；
6. 工控机实时通信中继。

Nav2 导航和 Frontier 自动建图仍保留独立控制；“手动建图”会在基础模块就绪后补充 Nav2，“自动建图”再补充 Frontier。关闭“基础功能模块”或点击“全部停止”会调用工控机运行代理的整栈停止路径：先请求 Frontier 释放导航目标，再回收全部受管 ROS2 进程。因此 SLAM 地图、导航与自动建图不会作为孤立进程遗留在工控机上。

安全停止在启动编排期间仍可使用；但已有运行中依赖的模块开关会禁用，防止用户先关掉 Nav2 的底层依赖而得到无效的停止请求。

## 地图、视频与导航交互

- “保存当前地图”和“导入地图”已移至 SLAM 地图顶部工具栏，和“清地图缓存”同行。导入时在一次文件选择中同时选择 YAML 与 PGM；文件会上传到工控机地图目录，当前 SLAM 不会被替换。
- 右侧 RealSense 视频区域提高最小高度，使 `1280×720` 预览在常用桌面尺寸下有更大的显示空间。
- Canvas 地图渲染现在通过 `requestAnimationFrame` 合并同一帧内的地图、路径、位姿、缩放和拖动更新；浏览器不会为一批并发状态更新重复重绘整张栅格地图。
- Nav2 目标处于“发送中”时即可取消。底盘急停在 Nav2 接管时会立即发送零速度、请求取消导航目标，并在完成后再次发送零速度，避免按钮文字与实际动作不一致。

## 验证

已完成：

- 前端 TypeScript 类型检查与生产构建：`npm --prefix frontend run build`；
- 配置和改动文件的静态检查：`git diff --check`。

本开发机仅有 Python 3.9，未保留 ROS2 Python 3.10 虚拟环境，不能在此处导入后端依赖进行完整测试。部署服务器应执行：

```bash
cd ~/WebProjects/WebRobotools/backend
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 ./.venv-ros2/bin/pytest
```

随后在安全场地验证：启动/关闭基础功能模块、手动遥控建图、自动建图及随时停止、地图保存/导入、Nav2 发送中取消，以及地图和视频是否持续显示最新数据。

## 安全边界

软件“停止”会回收本项目运行代理管理的 ROS2 进程，不替代物理急停，也不应被视作关闭操作系统中所有无关程序。机器人移动或自动建图时必须保持人员监护和可触达的硬件急停。
