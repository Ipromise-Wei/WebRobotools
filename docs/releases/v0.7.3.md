# v0.7.3 版本说明

发布日期：2026-09-28

本版按现场要求完全关闭实时视频可视化，将 CPU 和网络资源优先留给 Nav2、地图与控制通信。

## 关闭范围

- `visualization.realsense.enabled` 设置为 `false`，后端不会启动 RealSense 采集线程。
- 工控机不会再启动 `camera_relay.py` 与 FFmpeg，也不会建立视频 SSH 通道。
- 底盘页面移除 RealSense 画面组件，不会请求 `/api/visualization/camera/stream`。
- 机械臂页面移除视频图像请求和每秒一次的相机状态轮询，仅显示机械臂实时状态。
- 底盘右侧控制台填充原视频区域，页面不再为视频保留运行空间。

部署前检查发现工控机仍运行一组旧的 `camera_relay.py` 与 FFmpeg 进程，FFmpeg 当时约占 13.9% CPU。定向停止后，旧 Web 后端因浏览器仍连接视频接口而重新拉起进程，说明单独终止工控机进程不能稳定关闭视频。部署本版时必须重启 Web 后端，并强制刷新或关闭旧浏览器页面。

## 验证

- 前端 TypeScript 类型检查与生产构建通过：`npm --prefix frontend run build`。
- YAML 配置检查确认 RealSense `enabled` 为 `false`。
- 现场复现确认旧后端会自动重启视频中继；本版从配置和所有页面入口同时关闭视频，避免新版后端再次建立该链路。

服务器升级并重启后，浏览器需要强制刷新，使旧页面建立的 MJPEG 连接彻底退出。
